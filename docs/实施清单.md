# 商品资料自动整理与检查实现说明

目标：本机上传商品Excel/CSV，统一明确格式，检查缺项、重复SKU、售价及库存，展示问题并导出结果。使用Python、pandas、openpyxl和Streamlit，依赖安装在独立项目环境中。

## 范围与验收

- 输入同一店铺、同一时间及价格口径的商品表；一行一个SKU。
- 必填字段：商品名称、SKU编码、规格、售价、库存。自动识别明确别名，并可手动选择原列。供货价、拼单价、单买价不自动猜作通用售价。
- 保留额外列、原始值、修改记录及所有重复行；不覆盖源文件，不猜测价格库存。
- 价格为正数且最多两位小数；库存为非负整数，零库存有效。相同SKU不同价格标为待核对，不能据此自动判定哪条正确。
- SKU以文本保存，Excel数字型SKU提示核对；公式仅保留原表达式并提示，不使用缓存当成已核实资料。
- 上传上限5MB、5000行、80列。支持UTF-8/BOM、GB18030的CSV；Excel可选择可见工作表。文件或列歧义给出明确提示。
- 输出Excel含整理结果、问题清单、修改记录、原始资料、说明；可单独下载HTML汇报。上传资料只在当前进程内存处理。
- 演示资料明确标注虚构。统计显示真实行数、问题数、修改数和实际程序处理耗时，不虚构节时比例。
- Git仓库保留源码、说明、测试及虚构演示截图；虚拟环境、缓存、临时测试下载件、密钥配置与业务数据目录不纳入版本管理。

## 文件及共享接口

### checker.py

常量`FIELDS = ["商品名称", "SKU编码", "规格", "售价", "库存"]`、`MAX_BYTES=5*1024*1024`、`MAX_ROWS=5000`、`MAX_COLS=80`。

- `load_upload(filename: str, payload: bytes, sheet_name: str | None = None) -> dict`
- `list_workbook_sheets(payload: bytes) -> list[str]`：先读取可见表名，再显示选择器，封面页错误不阻断其他表选择。
- `demo_table() -> dict`
- `guess_mapping(headers: list[str]) -> dict[str, str | None]`
- `analyze_table(table: dict, mapping: dict | None = None) -> dict`

table结构：`source:str, sheet:str, sheet_names:list[str], headers:list[str], rows:list[list[str]], row_numbers:list[int], formulas:list[{row:int,column:str}], numeric_cells:list[{row:int,column:str}], notices:list[str]`。表头第一行，实际数据行号从2起且跳空行后保持来源行号。demo为10行服装类虚构资料，包含合法零库存与文本SKU000087。

mapping从五个标准字段指向原表头，未选择为None。多个标准字段指向同一原列需拒绝。表头重复、空表头内有数据、80列/5000行/5MB超限需拒绝，不丢弃数据。

report结构：`source:str, sheet:str, generated_at:str(北京时间), mapping:dict, columns:list[str], rows:list[Row], file_issues:list[Issue], notices:list[str], summary:dict`。

Row：`row:int, raw:dict[str,str], data:dict[str,str], issues:list[Issue], changes:list[{field:str,before:str,after:str}], status:str`。status为`通过`、`需修正`、`待核对`，有错误则需修正，否则有核对项则待核对。data含五个标准列，未映射原列以`原列·原表头`命名保留。

Issue：`code:str, field:str, level:str("错误"或"待核对"), message:str, suggestion:str`。file_issues为整表问题；行问题同时定位所缺字段，不能产生缺列却显示全部通过的报告。

summary：`total_rows:int, passed_rows:int, issue_rows:int, error_rows:int, review_rows:int, issue_count:int, normalized_cells:int`。passed_rows+issue_rows=total_rows，error_rows+review_rows=issue_rows，issue_count包含整表和行问题。

### exporting.py

- `export_xlsx(report: dict) -> bytes`
- `export_html(report: dict) -> bytes`
- `template_xlsx() -> bytes`
- `table_xlsx(table: dict) -> bytes`

Excel所有源字符串按字面量保存，避免公式执行；SKU为文本，规范售价和库存可写数值但仅在该字段无错误且数值明确时。HTML全部来源字段转义。模板带五列及单独填写说明页，示例导出保留源表格式。

### app.py / ui.py / launch.py

页面：文件上传或载入演示、工作表选择、字段对应确认、检查按钮、真实统计、问题筛选、规范表/问题/修改/原始资料切换、Excel及HTML下载。输入或映射变化必须隐藏旧结果，防止导出陈旧报告。

视觉：参考Excel按行定位、Power Query核对原值、Airtable按状态筛选。普通CSS辅助Streamlit，浅灰底、深绿主色、文字与颜色共同表达状态；窄屏表格独立横向滚动。
